# 机械方向

中期考核分为兑矿车（100分）和固定发射架（30分，选交）。两模块分别评分后求和，再除以 1.3 折算为百分制；折算达到 60 分及以上通过。

## 兑矿车（100分）

- [ ] 底盘（40分）：完成结构设计、驱动布局、装配与干涉检查。
- [ ] 资源拾取/存储机构（25分）：明确拾取方式、容量、限位和防掉落设计。
- [ ] 资源兑换机构（35分）：明确对接、释放/交付动作及驱动方式。
- [ ] 完成兑矿车装配体文件。
- [ ] 自制零件标注标准螺丝孔位、拼插孔位或热熔胶使用位置。

## 固定发射架（选交，30分）

- [ ] 明确发射架结构和运动/调节方式。
- [ ] 完成装配体（如参加该项）。
- [ ] 检查零件干涉和加工可行性。

## 交付

- [ ] 兑矿车装配体文件
- [ ] 固定发射架装配体文件（选交）
- [ ] 结构说明文档（建议 PDF）
- [ ] 检查自制零件连接与孔位标注

等级参考：A 85–100；B 60–84；C 40–59；D 0–39。标准件（螺丝、螺母）装配不作要求。

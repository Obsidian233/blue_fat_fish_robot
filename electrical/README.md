# 电控方向

考核总分 40 分，B 级为 21–30 分。

## 考核任务

- [ ] 1. 遥控器对频，单片机解包遥控协议（3分）。
- [ ] 2. 串口实现单片机与电脑通信，输出调试信息（3分）。
- [ ] 3. 云台动力设备（舵机、步进电机等）角度控制（10分）。
- [ ] 4. 底盘动力设备速度控制（10分）。
- [ ] 5. 远程控制任一动力设备的角度或速度；建议遥控小车演示（10分）。
- [ ] 6. 学习 Git 并用于代码管理（3分）。

## 推荐推进顺序

1. 建立固件工程与 Git 仓库，完成串口打印。
2. 完成遥控器对频和协议解析，记录数据帧格式。
3. 单独验证舵机角度控制。
4. 单独验证电机速度控制与反馈。
5. 将遥控输入映射到动力设备，完成整车演示。
